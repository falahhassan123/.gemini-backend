🤖 Gemini Backend API

Welcome to the Gemini Backend API. This API provides image analysis capabilities using Google's Generative AI.

API Endpoint

POST /api/analyze

Request Body:

{
  "image": "base64_encoded_image_data",
  "prompt": "Your analysis prompt here"
}

Response:

{
  "text": "AI-generated response"
}

Getting Started

  1. Set your Gemini API key in the api/analyze.js file
  2. Send POST requests to /api/analyze with an image and prompt
  3. Receive AI-generated analysis responses
